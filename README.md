# Проект «Файловый археолог» (Этап I) — Терминальный навигатор по Windows FS

## 🌌 Описание проекта
**Год разработки решения:** 2026.  
**Сеттинг:** 2142 год. Команда цифровых археологов обнаружила древний сервер начала XXI века под управлением ОС Windows. Стандартные инструменты сломаны. Разработанное решение — это специализированный консольный менеджер-навигатор, написанный на чистом Python, который умеет обходить ограничения поврежденной системы, собирать глубокую статистику и искать скрытые цифровые артефакты ушедшей цивилизации.

---

## 🛠 Что было сделано (Реализованный функционал)
В рамках **I этапа** спроектирована и написана с нуля отказоустойчивая модульная архитектура приложения. Все модули полностью соответствуют стандарту **PEP8**, используют явную аннотацию типов и работают без сторонних зависимостей.

### Разработанные модули и зоны ответственности:
1. **`utils.py` (Архитектор системы):** 
   * Реализована проверка среды выполнения (`platform`).
   * Написан валидатор Windows-путей (контроль длины до 260 символов, проверка дублирования двоеточий, фильтрация запрещенных символов `* ? " < > |`).
   * Написан конвертер байтов в Windows-формат размеров (`KB`, `MB`, `GB` на базе деления на 1024).
   * Интегрировано низкоуровневое чтение скрытых и системных атрибутов через Windows WinAPI (`ctypes.windll.kernel32`).
2. **`navigation.py` (Инженер навигации):**
   * Реализовано безопасное сканирование дисков и папок (`os.listdir` обернут в перехватчики `PermissionError` и `OSError`).
   * Добавлена логика безопасных переходов вверх (`cd ..`) и вниз с автоматической сборкой абсолютных путей.
   * Написан механизм обнаружения всех активных логических дисков в системе (`GetLogicalDrives`).
   * Добавлен быстрый переход в системные папки (`Desktop`, `Documents`, `Downloads`) через чтение переменных окружения Windows.
3. **`analysis.py` (Аналитик данных):**
   * Реализованы рекурсивные алгоритмы подсчета количества файлов и их суммарного веса.
   * Интегрирована защита от зацикливания: алгоритм автоматически игнорирует системные ссылки (Junction Points) и символические ссылки (`symlinks`).
   * Написан сборщик статистики распределения файлов по расширениям с выводом ТОП-5 самых "тяжелых" типов данных.
4. **`search.py` (Эксперт поиска):**
   * Создан рекурсивный поисковый движок с поддержкой Windows wildcards (`*` и `?`). Поиск по умолчанию работает в регистронезависимом режиме, как в нативной Windows.
   * Добавлен массовый поиск по списку расширений (например, выуживание всех исполняемых файлов `.exe, .dll, .sys` за один проход).
   * Реализован фильтр поиска аномально крупных файлов (археолог задает минимальный размер в мегабайтах).
5. **`main.py` (Архитектор системы):**
   * Собрана единая консольная экосистема. Навигация и вызов подсистем управляются через современный синтаксис `match-case`.
   * Добавлен глобальный перехват критических ошибок и прерываний (`Ctrl+C`), защищающий программу от внезапного падения.

## 📂 Структура проекта
Для корректной работы файлы должны лежать в одной директории:
```text
file_archaeologist/
├── main.py              # Точка входа, интерфейс и главный цикл
├── utils.py             # Базовые низкоуровневые утилиты ОС
├── navigation.py        # Модуль перемещения и чтения директорий
├── analysis.py          # Рекурсивный аналитический движок
└── search.py            # Поисковый модуль (маски, фильтры, размеры)
```

## 🚀 Инструкция по запуску

> ⚠️ **Важное требование:** Программа жестко завязана на архитектуру Windows путей и WinAPI. Запуск необходимо производить на операционной системе **Windows**.

### Шаг 1. Подготовка файлов
Убедитесь, что все 5 файлов (`main.py`, `utils.py`, `navigation.py`, `analysis.py`, `search.py`) скопированы в одну общую папку на вашем компьютере.

### Шаг 2. Запуск терминала
Откройте командную строку Windows (`cmd`) или `PowerShell`:
1. Нажмите комбинацию клавиш `Win + R`.
2. Введите `cmd` и нажмите `Enter`.

### Шаг 3. Переход в папку с проектом
Используя команду `cd`, перейдите в директорию, где лежат ваши скрипты. Например:
```bash
cd C:\Users\ВашеИмя\Projects\file_archaeologist
```

### Шаг 4. Старт программы
Запустите главную точку входа через интерпретатор Python:
```bash
python main.py
```

### 💡 Как пользоваться приложением:
* После запуска перед вами появится интерактивное меню.
* Вы можете вводить как цифры (`1`, `2`, `3`), так и привычные терминальные команды (`ls`, `cd ..`, `cd ИмяПапки`, `анализ`, `поиск`).
* Чтобы изучить вложенные папки, нажмите `4` (запустится рекурсивный сканер объема данных) или нажмите `5`, чтобы отсеять файлы по маске.
* Для безопасного выхода из программы введите `0` или `exit`.
